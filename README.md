# 🔐 Autonomous Campus Security System (Arduino)

## 📌 Description

This project is my undergraduate thesis. It focuses on building a simple and low-cost security system using Arduino to help improve safety on campus.

## 🎯 Objective

To detect movement and alert users when there is possible intrusion.

## ⚙️ Components

* Arduino Uno
* PIR motion sensor
* Ultrasonic sensor
* Buzzer
* LEDs

## 🚀 How it works

* The sensors monitor the environment
* When motion is detected, the system triggers an alarm
* The buzzer and LEDs alert users

## 💡 Result

The system works in real time and can help improve security in schools or small areas.
